Distributions

gnosh needs a GTK 3 Phosh, gjs ≥ 1.74, python3 and glib-compile-schemas. It doesn't use libphosh. The Phosh module is prebuilt for x86_64, aarch64, armv7l and riscv64 (glibc and musl).

GNOME Shell versions

gnosh implements the extension API of GNOME Shell 50 and loads extensions made for GNOME Shell 45–51 (ES modules). When it installs from extensions.gnome.org it picks the GNOME 50 build, or the newest older one. GNOME ≤ 44 extensions (the old imports.* module system) are not supported.
