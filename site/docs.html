Installing

curl -fsSL https://raw.githubusercontent.com/exynos-linux/gnosh/main/setup.sh | sh   # latest release
./setup.sh                      # from a git checkout
./setup.sh --version 0.1.0      # a specific release
./setup.sh --no-extension-manager --no-gext --no-auto-update
./setup.sh --uninstall          # keeps extensions and settings

What gets installed (all in your home directory):

PathWhat
~/.local/bin/gnoshthe command
~/.local/share/gnosh/runtime/the runtime (JavaScript)
~/.local/lib/gnosh/libgnosh-phosh.sothe GTK module that starts gnosh inside Phosh
~/.config/systemd/user/mobi.phosh.Shell.service.d/50-gnosh.confsets GTK_MODULES for Phosh
~/.config/systemd/user/gnosh-update.timerdaily gnosh self-update and gnosh update
~/.local/bin/gextgnome-extensions-cli wrapper (filesystem backend)
~/.config/gnosh/config.jsongnosh settings

The gnosh command

CommandWhat it does
gnosh statuswhether gnosh runs in Phosh, and extensions with problems
gnosh list [-v] [--enabled] [--json]installed extensions and their state
gnosh search TERMsearch extensions.gnome.org (only extensions with a GNOME 45–51 build)
gnosh install UUID|URL|TERM|FILE.zipinstall, compile settings schemas, enable and load into the running Phosh
gnosh enable|disable UUID [--phosh-only]uses GNOME's setting, or with --phosh-only only gnosh's
gnosh uninstall UUIDremove a user-installed extension
gnosh prefs UUIDopen the extension's preferences
gnosh info UUIDdetails, including whether it is supported in Phosh
gnosh update [--check] [UUID…]newer versions from extensions.gnome.org (run after the next login)
gnosh self-update [--check]install the newest gnosh release from GitHub (checksum verified)
gnosh doctorcheck the installation and explain what is wrong
gnosh shell status|enable|disable|pause|resetcontrol whether gnosh loads into Phosh; reset clears the crash guard
gnosh config [KEY [VALUE]]shell-version, allow-unsupported, auto-update
gnosh loggnosh's messages from this boot's Phosh log

gnosh refuses to run outside Phosh. Over ssh it works when Phosh runs for your user.

Where extensions show up

  • Top bar: panel indicators and quick settings indicator icons, in Phosh's status icon area. Tapping one opens the quick settings drawer at its page.
  • Quick settings: one tile per indicator menu and per quick settings item. Tapping a toggle switches it, and the arrow (or tapping a menu-only tile) opens its page. A Settings button at the bottom of the page opens the extension's preferences when its menu has no settings item.
  • Dialogs: extension dialogs appear as Phosh system dialogs.
  • Notifications: they go to Phosh's notification list, with buttons for their actions.

Limitations

  • Extensions that change GNOME Shell itself (dock, overview, panel replacements, window tiling, workspaces, blur and other compositor effects, shell themes) can't work in Phosh. gnosh refuses them with a reason (runtime/data/compat.json).
  • No animations: eased properties jump to their final value and completion callbacks still run.
  • Main.layoutManager.addChrome() overlays (floating widgets on the stage) are kept but not shown.
  • Windows: gnosh knows the app id and fullscreen and maximized state of open apps (from Phosh's overview), but not which one is focused, and it can't move or close windows.
  • Clipboard monitoring only sees changes while Phosh has keyboard focus, for example while the drawer is open. Setting the clipboard works.
  • No XEmbed tray icons (there is no X11 in phoc). StatusNotifier icons through the AppIndicator extension work.
  • Extensions can't be updated in a running shell; updates apply after the next login, as in GNOME Shell.

Troubleshooting

gnosh doctor          # step-by-step checks
gnosh log             # gnosh messages from Phosh's journal
gnosh list -v         # per-extension errors
  • Phosh fails to start or loops: gnosh stays out after two unstable starts. Run gnosh shell reset once you have fixed the cause, or gnosh shell disable to stop loading it.
  • "settings schema could not be found": install glib-compile-schemas (Alpine/pmOS glib, Debian libglib2.0-bin, Fedora glib2).
  • Extension Manager says GNOME Shell is not running: gnosh isn't running in Phosh. Check gnosh doctor.
